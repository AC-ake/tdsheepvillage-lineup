# 保卫羊村 · 布阵工具

纯前端、离线可用的布阵规划工具：选地图 → 选塔 / 宝石 / 等级 → 点格子放塔，
实时算出这张图的总造价、画出狼的行走路线与每座塔的攻击范围，按本图配置随机模拟出狼，
还能按塔的攻击力 / 攻速 / 射程预测这一波能不能守住，并生成「种子码」分享给别人。

## 打开方式

双击 `index.html`（推荐 Chrome / Edge）。整个文件夹就是完整的程序，可以随便拷贝、压缩发送。

如果双击后画面空白或存档存不上（少数浏览器会限制本地文件的存储），
在本文件夹里执行一次 `python -m http.server 8765`，再访问 http://127.0.0.1:8765/index.html 。

## 玩法规则（工具都按这些规则判定）

- **狼按四方向走**，不走折线。
- **出狼口按箭头方向出狼**：顺着箭头方向的第 1 格是有效路线起点，这一格**不能放建筑**，
  所有出狼口一个都不能堵；出狼口本身也不能建塔。
- **入村口按箭头方向进村**；羊村范围画成一片的（3×3 等多格）只以带标注的那格为入村口，
  其它格子按同色显示但算障碍：不能建塔、也不参与路线。入村口可以堵，**至少要留 1 个**。
- **传送口按颜色配对**：踩到「传送入」一定会被送走，只送到同色的「传送出」；
  一个「传送入」对多个「传送出」时（如苏兰德城）会画出多条路线，路线在传送处断成分段。

## 功能

**选地图**：第一大图 / 第二大图 / 第三大图 / 第四大图，外加与它们并列的**大本营防线**，
共 47 张图；编号与图册一致（1 巴罗村 …… 38 防线 …… 46 枫威瀑布）。
左上角标题统一写成「第 N 图 · 地图名 · 前线」（大本营防线写作「防线」）。

**建塔**：塔型（上限写在按钮上）→ 宝石（无，以及红·绿·黄·紫·蓝·黑 × 碎片 / 晶体 / 宝石 /
精华 / 强化，共 31 种）→ 等级 → 点格子放置。塔身上直接显示等级与宝石档位缩写
（如「炮：强化」在列表里、塔身上显示「强化」），鼠标划过可看完整信息。
**按住 Ctrl + 左键拖动可以连续造同样配置的塔**，松开左键停止，整批只算一步撤销。

**造价统计**：本图总造价（超过参考收入会标红）、各塔种小计、参考收入；
升级经验只在大本营防线显示。

**已布置**：列出每座建筑（缩写 + 宝石颜色点 + 造价），并统计**当前用了多少颗宝石**——
按颜色分品质列出，例如「黑精华×1、黑碎片×2、红精华×1、红晶体×1」。

**图例 · 地图说明**（左侧）：只列出**当前这张图实际有的**地形类型；本图特有的地形
（图册「注：」里列的，比如爆炸箱、传送带、铁路、特殊塔位、障碍）也会带颜色列进图例，
下面再跟图册原文说明；鼠标划过格子会显示该格的具体类型与标注。

> 地图不一定是矩形：出入口画在网格外时（例如梨花冰场的出狼口在矩形上方两格），
> 工具会把网格扩到包含它，并把狼走进来那段通道标成「只能走狼」。

**模拟出狼 · 走狼预测**：按本图自己的出狼配置随机抽一波（例如凌绽雪原只会出飞天狼 / 机械狼 /
神偷狼 / 杨六狼 / 花狼）。可以填「进度」和「波难度」：
狼等级 L = √(ha + hb × 进度)，每只狼血量 = ⌊(a + L(b + L·c)) × 波难度⌋。

> **数据保守，仅供参考**：未计入狼的隐身、狂奔、召唤、复活、护盾、群体治疗等技能，并且大多数种类宝石效果的发生以及沉默的延时无法计入，
> 也未计入传送带、火山 / 反应炉等地形与塔的攻速加成。属于按面板数据估算，不是逐帧还原游戏本体。所以这玩意也就图个乐呵，四图模拟出狼计算量太大基本都是打不动（

**走狼路线**：画出每个出狼口到羊村口的最短路线；多口时会汇聚或分散，传送一对多时分成多条。

**攻击范围**：颜色 = 所镶宝石颜色，透明度可调；被织女雕像加成时用虚线画加成后的范围。

**种子码**：点「生成种子码」得到一串 `YC1-...` 短码（含地图、每座建筑的类型 / 宝石 / 等级
以及手工改过的地形）。别人粘贴后点「载入种子码」即可复现。

**进度保存**：每次操作自动存进浏览器（localStorage）；`Ctrl+Z` 撤销。
「改地形」画笔可修正任何格子；「底图对齐」把地图原画拖到网格下面做参照。

## 数据来源

- 地图格子（可走 / 可建 / 出狼口 / 羊村口 / 障碍 / 传送 / 只能建塔 / 只能走狼 / 金字塔等）：
  《保卫羊村百科全书V1.82》工作表「前线、防线地图」里作者逐格画的空白地图；
  同一张图有旧版 / 新版两份时**以新版为准**（如远古冰川、缠怨谷）。
- 塔造价、升级经验：工作表「各种塔造价、攻击力」与「防线塔造价、经验」。
- 宝石效果（减速 / 毒 / 燃烧）：工作表「宝石功能」。
- 塔的攻击力、射程、攻速、等级上限，宝石的攻击力与射程倍率：
  游戏配置 `sys_config.json`（与百科的镶嵌塔各列、「宝石功能」百分比逐项一致）。
- 出狼配置（每张图出哪些狼、pop、血量系数、难度系数表）：`sys_config.json` 的
  `umaps[].wolf_proportion` 与 `wolfs[].hp_factor`；血量与等级算法与羊村百科
  「Umap Detail / 波工具」页一致（已用巴罗村、凌绽雪原逐值核对）。
- 参考收入、大图编号与顺序：《保卫羊村全地图布局参考 2026.7.pdf》每页标题。

### 需要说明的几处

1. 缠怨谷、枫威瀑布的图册里出入口没画箭头，工具按「只有一个可走邻居就用它，否则用该格自身」兜底。
2. 少数图册标注写着「印象久远可能有误」，遇到和游戏对不上的格子，用「改地形」改掉即可。
