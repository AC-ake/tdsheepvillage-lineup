# 保卫羊村 · 布阵工具

纯前端、离线可用的布阵规划工具。双击 `index.html` 即可使用（推荐 Chrome / Edge），
整个文件夹就是完整的程序，随便拷贝或压缩发送都行。

如果双击后画面空白或存档存不上（少数浏览器会限制本地文件的存储），
在本文件夹里执行一次 `python -m http.server 8765`，再访问 http://127.0.0.1:8765/index.html 。

## 功能

**选地图**：按第一大图 / 第二大图 / 第三大图 / 第四大图 / 大本营防线 分组，共 47 张图，
另有一组「自定义」，可以建多张自定义地图、随时改名，自己定几乘几、自己摆出入口和各种障碍、
自己加要出的狼与进度上限。

**建塔**：选塔型 → 选宝石（无 / 红绿黄紫蓝黑 × 碎片·晶体·宝石·精华·强化）→ 拉等级，
点格子放置；鼠标在图上移动时，光标右上方会跟着显示当前选中的塔，**滚轮可以切换塔型**；
塔身上会显示等级和宝石档位，按住 Ctrl + 左键拖动可以连续造同样的塔。

**造价统计**：实时显示本图总造价、各塔种小计、参考收入（超过参考收入会标红）。

**已布置**：列出每座建筑，并统计当前用了多少颗宝石（按颜色分品质）。

**地图符号**：图册里的特殊地形会按名字区分画在格子上（弹簧 = 红 X、弹簧落点 = ⓧ、
钢网桥 = 灰色方格、有洞的钢网桥 = 带圈的灰色方格、爆炸箱 = 红 X、传送带 = 浅黄箭头……），
左侧图例里有本图用到的符号对照。

**模拟出狼**：按本图配置随机出一波狼，也可以单独生成本图的随机 Boss；
再用「模拟走狼」预测这一波能不能守住、有没有狼进村、进村还剩多少血。
模拟用的就是你当前抽到的那一波狼（还会统计这一波里各种狼技能发动了多少次）。
【数据保守，仅供参考】

**走狼路线**：画出每个出狼口到羊村口的最短路线；会飞的狼走的是另一条蓝色虚线路线
（按飞行高度 1100 计算：地图外围高山飞不过去，内部矮障碍直接飞过，特殊塔位上的高塔要绕开；
仍按四方向走相对最短的一条路到村口，并按箭头方向进村）。飞行路线按游戏里的样子画成折线：
全程拐弯 2~4 次、两次拐弯之间至少直飞 2 格、只朝村口方向前进不会往回飞，
遇到高障碍要绕开时会多一点弯，但不会出现每格都拐的抖动。
选哪一条折线只看两件事：**先保证不绕远路**（长度和最短的那条一样），
一样长时优先经过玩家塔位多的地方，其中出狼口那半程经过的塔更重要
（游戏里飞狼起手会朝塔密集的点位拐）。

同一只出狼口如果有多条能走的路（呼噜噜村、虎克工厂这种并排的两条通道、一对多的传送口），
**几条都会画出来**；模拟时狼走哪一条按游戏里的寻路规则定：每只狼走过一条路，会把这条路
对后来狼的开销改掉（charm，多数狼是负值＝排斥），所以前面的狼走了一条、后面的狼会走另一条，
一次模拟几条通道都会用上，几率接近对半、稍微偏向短的那条。

**路线颜色**：走狼路线和飞行路线的颜色可以自己改（默认黄 = 走狼、蓝 = 飞行），
看不清的时候（例如色盲、或深色底图上）换两个显眼的颜色就行，改完会记住。

## 特殊地形怎么算

数值来自百科「前线、防线地图」页和游戏配置，都是「影响周围一格」：

| 地形 | 周期 | 对狼 | 对塔 |
|---|---|---|---|
| 小火山 2×2 | 7 秒 | 血量 2% 的燃烧伤害（至多 5000） | 封塔 4 秒（不攻击） |
| 大火山 3×3 | 10 秒 | 血量 4% 的燃烧伤害（至多 10000） | 封塔 6 秒 |
| 反应炉 | 10 秒 | 减速 50%，2 秒 | 攻速 ×0.5，6 秒 |
| 核电厂 | 4 秒 | 1000 点电伤害（免疫电的狼不受伤） | 攻速 ×2，4 秒 |
| 传送带 | — | 箭头与狼走的方向一致 +30% 速度，不一致 −30%（百科没给数值，先这么设定） | — |
| 弹簧 | 每 5 秒一次、最多 5 次 | 被弹到落点后晕 1 秒；**没被弹到落点的狼腾空 0.5 秒，这期间算飞狼**（散弹塔双倍伤害与效果、炮塔和波动塔索敌不到） | — |
| 爆炸箱 | 被推 4 次爆炸 | 狼后退一格 | 爆炸时和自爆狼一样罩住周围一圈的塔（范围 2 格、乌云 2 秒） |

转生也有讲究：天空萝莉在天上被打死会转生成陆地形态，落点在障碍物或建筑之间时，
会先按它自己的移速走回正常走狼路线再继续（游戏里的 jostle）。

### 模拟强度校准

塔的攻速按笔记计算（基础攻速 × 状态 × 墙加速，向上取整后每帧从 2500 里扣），
另外整体乘了一个校准系数 `TOWER_RATE_MUL`（现在 = 2），用来把模拟结果对齐到游戏实测：
按面板原始数值跑，防线的挂机强度会偏低，3999 进度 / 1.3 难度偶尔漏狼；
乘 2 之后连续 8 次高压波测试都是 0 漏（最后一只基本在村口前被打死）。
如果你觉得塔偏强，把程序里 `let TOWER_RATE_MUL = 2.0;` 这一行改小即可（1 = 完全按面板数值）。

连锁闪电按「逐跳找最近的下一只、每跳不超过 3 格」结算，几座紫镶嵌同时开火会织成连锁网；
乌云只会罩「范围内最近的、实力不低于平均值一半」的塔（笔记里的规则）。

**攻击范围**：画出每座塔的攻击范围，颜色跟随所镶宝石，透明度可调。

**种子码**：把当前布阵生成一串短码发给别人，对方粘贴后即可复现同样的布阵。

**进度保存**：操作会自动保存在浏览器里，支持撤销、清空本图与全部重置。

## 自动更新

工具里的「更新」一栏可以检查有没有新版，检查的地址是写在程序内部的，界面上改不了，
也不接受别人二次分享时改成别的网址：

    仓库首页（给人看的）：https://github.com/AC-ake/tdsheepvillage-lineup
    工具取文件的地址：    https://raw.githubusercontent.com/AC-ake/tdsheepvillage-lineup/main/
                        （以及 GitHub Pages、master 分支两个备用地址）

程序会先把地址解开、再和内置指纹比对，对不上就认定文件被改动过，
此时会直接停止联网更新、也不跳转任何网址，只提示重新到仓库下载原版。

新版本发布时，把程序里的版本号和同目录 `version.json` 的版本号一起改大再上传，
旧版本的用户点「检查更新」就会看到提示。

## 需要说明的几处

如果发现某张图的格子和游戏里对不上，属于图册本身标注「印象久远可能有误」的部分，
用「改地形」画笔改一下就好（改动会记住，也能写进种子码）。

如有底图对不齐的情况也属正常。
