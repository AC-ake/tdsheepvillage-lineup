# 保卫羊村 · 布阵工具

纯前端、离线可用的布阵规划工具。双击 `index.html` 即可使用（推荐 Chrome / Edge），
整个文件夹就是完整的程序，随便拷贝或压缩发送都行。

如果双击后画面空白或存档存不上（少数浏览器会限制本地文件的存储），
在本文件夹里执行一次 `python -m http.server 8765`，再访问 http://127.0.0.1:8765/index.html 。

## 功能

**选地图**：按第一大图 / 第二大图 / 第三大图 / 第四大图 / 大本营防线 分组，共 47 张图，
另有一组「自定义」，可以建多张自定义地图、随时改名，自己定几乘几、自己摆出入口和各种障碍、
自己加要出的狼与进度上限。

**建塔**：选塔型 → 选宝石（无 / 红绿黄紫蓝黑 × 碎片·晶体·宝石·精华·强化）→ 拉等级，
点格子放置；鼠标在图上移动时，光标右上方会跟着显示当前选中的塔，**滚轮可以切换塔型**；
塔身上会显示等级和宝石档位，按住 Ctrl + 左键拖动可以连续造同样的塔。

**造价统计**：实时显示本图总造价、各塔种小计、参考收入（超过参考收入会标红）。

**已布置**：列出每座建筑，并统计当前用了多少颗宝石（按颜色分品质）。

**地图符号**：图册里的特殊地形会按名字区分画在格子上（弹簧 = 红 X、弹簧落点 = ⓧ、
钢网桥 = 灰色方格、有洞的钢网桥 = 带圈的灰色方格、爆炸箱 = 红 X、传送带 = 浅黄箭头……），
左侧图例里有本图用到的符号对照。

**模拟出狼**：按本图配置随机出一波狼，也可以单独生成本图的随机 Boss；
再用「模拟走狼」预测这一波能不能守住、有没有狼进村、进村还剩多少血。
模拟用的就是你当前抽到的那一波狼（还会统计这一波里各种狼技能发动了多少次）。
【数据保守，仅供参考】

**走狼路线**：画出每个出狼口到羊村口的最短路线；会飞的狼走的是另一条蓝色虚线路线
（按飞行高度 1100 计算：地图外围高山飞不过去，内部矮障碍直接飞过，特殊塔位上的高塔要绕开；
仍按四方向走相对最短的一条路到村口，并按箭头方向进村）。

**攻击范围**：画出每座塔的攻击范围，颜色跟随所镶宝石，透明度可调。

**种子码**：把当前布阵生成一串短码发给别人，对方粘贴后即可复现同样的布阵。

**进度保存**：操作会自动保存在浏览器里，支持撤销、清空本图与全部重置。

## 自动更新

工具里的「更新」一栏可以检查有没有新版，检查的地址是写在程序内部的，界面上改不了，
也不接受别人二次分享时改成别的网址：

    仓库首页（给人看的）：https://github.com/AC-ake/tdsheepvillage-lineup
    工具取文件的地址：    https://raw.githubusercontent.com/AC-ake/tdsheepvillage-lineup/main/
                        （以及 GitHub Pages、master 分支两个备用地址）

程序会先把地址解开、再和内置指纹比对，对不上就认定文件被改动过，
此时会直接停止联网更新、也不跳转任何网址，只提示重新到仓库下载原版。

新版本发布时，把程序里的版本号和同目录 `version.json` 的版本号一起改大再上传，
旧版本的用户点「检查更新」就会看到提示。

## 需要说明的几处

如果发现某张图的格子和游戏里对不上，属于图册本身标注「印象久远可能有误」的部分，
用「改地形」画笔改一下就好（改动会记住，也能写进种子码）。

如有底图对不齐的情况也属正常。
